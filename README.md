
# Ad2Donate 🌱

A donation-themed web application built as a learning project.

## Features
- User registration and login
- Session-based authentication
- User credit tracking
- Donation amount tracking
- Donation cause selection
- Donation history retrieval

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Project Structure
- `index.php` — user dashboard
- `login.html` — login and registration forms
- `login.php` — user login
- `register.php` — user registration
- `logout.php` — logout functionality
- `db.php` — database connection
- `getUser.php` — retrieve user information
- `getHistory.php` — retrieve donation history
- `updateCredits.php` — update user credits and donation totals
- `script.js` — dashboard interactions
- `style.css` — page styling

## Setup Requirements
- PHP
- MySQL
- A local server such as XAMPP

## Status
Learning project — further testing, security improvements,
and donation verification are needed before production use.
